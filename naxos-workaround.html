Workaround for free Naxos Music Library access via your library ticket

The problem seems to be with the links on Naxos’s public libraries page. Here is a workaround. Go to the Naxos library access page, scroll down past the map and select your country (United Kingdom). Then select your library name from the dropdown that appears. This will display a web address link below. For example

buckscc.naxosmusiclibrary.com

for Buckinghamshire Libraries. DO NOT CLICK THE LINK. Instead, highlight and copy the TEXT of the link, then paste it into the address bar of your browser and press Enter (or Return).

You should now see a login screen for you to type in your library ticket number. No password is needed.
